URL Reputation Guard — Settings

You need at least one API key configured for the extension to check anything. More sources = better coverage.

VirusTotal Recommended

Free tier: 4 requests/min, 500/day. Get one from your VirusTotal account settings.

Google Safe Browsing Optional

Free tier: 10,000 requests/day. Enable the Safe Browsing API in Google Cloud Console and create an API key.

AlienVault OTX Optional

Free — sign up at otx.alienvault.com and find your key under Settings → API Integration.

URLhaus (abuse.ch) Optional

Free — register at auth.abuse.ch for an Auth-Key. Malware-URL specific — great complement to the general-purpose sources above.

Privacy: Keys are stored only in this browser's local extension storage (chrome.storage.local) — never synced, never sent anywhere except directly to each service's own API from your browser. Every URL you visit is sent to whichever sources you configure above so they can look it up — that's inherent to how reputation checking works. See the README's Privacy section for the full breakdown of what leaves your browser and where it goes.
